AURORA — MYSQL WORKBENCH HANDOFF
=================================

Give your teammate the repository (or at minimum database/aurora_workbench_full.sql).
The single-file script contains the complete schema, views, indexes, triggers,
RBAC tables, demo accounts, and aviation seed data. It is generated from
schema.sql + seed.sql so the Workbench copy does not drift from developer setup.

WORKBENCH SETUP
---------------
1. Install and start MySQL Server 8.0+ and open MySQL Workbench.
2. Connect to the local MySQL instance.
3. Open database/aurora_workbench_full.sql.
4. Execute the entire script (lightning bolt / Ctrl+Shift+Enter).
5. Refresh Schemas. Select aurora_db and expand Tables and Views.
6. Confirm 22 base tables (18 operational + 4 RBAC) and 4 views.

WARNING: The installer is a clean rebuild. It drops and recreates the project's
tables, views and triggers inside aurora_db, then reloads the demo data. Do not
run it over data that must be preserved.

LAUNCH THE APPLICATION
----------------------
1. In the project root, copy .env.example to .env.
2. Set DB_HOST, DB_PORT, DB_USER, DB_PASSWORD and DB_NAME=aurora_db.
3. Install Python dependencies: python -m pip install -r requirements.txt
4. Launch: python main.py

The app uses the same MySQL database initialized by Workbench. It no longer
silently switches to a separate local SQLite file.

VIVA / WORKBENCH QUERIES
-----------------------
USE aurora_db;
SHOW TABLES;
SHOW FULL TABLES WHERE Table_type = 'VIEW';
SHOW TRIGGERS;

-- Demonstrate RBAC mapping
SELECT r.role_name, p.permission_code
FROM app_role r
JOIN role_permission rp ON rp.role_id = r.role_id
JOIN app_permission p ON p.permission_id = rp.permission_id
ORDER BY r.role_code, p.permission_code;

-- Customer-facing departures view
SELECT flight_number, airline_name, departure_airport, destination_airport,
       scheduled_datetime, operation_status
FROM view_scheduled_departures
ORDER BY scheduled_datetime;

-- Unassigned operations (anti-join)
SELECT fo.operation_id, f.flight_number, ap.iata_code, fo.scheduled_datetime
FROM flight_operation fo
JOIN flight f ON f.flight_id = fo.flight_id
JOIN airport ap ON ap.airport_id = fo.airport_id
LEFT JOIN runway_assignment ra ON ra.operation_id = fo.operation_id
WHERE ra.assignment_id IS NULL
ORDER BY fo.scheduled_datetime;

-- Assignment audit trail
SELECT * FROM assignment_audit ORDER BY changed_at DESC;
